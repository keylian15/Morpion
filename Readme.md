# Morpion

Projet Bureau d'études Info (EILCO) : un Morpion en C.

## Installation

```bash
git clone https://github.com/keylian15/Morpion.git
cd Morpion
winget install ezwinports.make
```

Ferme et rouvre ton terminal après l'installation de `make`.

## Compilation et lancement

```bash
make          # compile le projet
./main.exe    # lance le jeu
make clean    # supprime l'exécutable
```
